# tubl
tube based solution

A lot of things are made out of tubes.

Why not use tubes to solve any kind of problems?

tubl uses tubes to solve any kind of problem.

## Features

### 🎨 Full 16-Color GUI
Complete tube-powered drawing interface with:
- All 16 tube-certified colors
- Brush, Line, Rectangle, Circle, and Tube Fill tools
- Adjustable brush sizes (2px – 40px)
- Save your tube art as PNG

### 🖱️ Trackpad / Trackball Input Modes
Navigate the tubes your way:
- **Trackpad Mode** — smooth multi-touch tube surface navigation
- **Trackball Mode** — classic tube-encased 360° precision control
- **Tube Pointer** — point the tube at what you want
- **Mind Tube** — experimental neural-tube interface (cranial adapter sold separately)

### 🎵 Soundtrack
Tube-enhanced audio featuring:
- **Mega Man 6 OST** (6 tracks): Title, Mr. X Stage, Plant Man, Flame Man, Knight Man, Ending
- **Led Zeppelin** (5 tracks): Immigrant Song, Whole Lotta Love, Kashmir, Stairway to Heaven, Black Dog
- **Tetris Theme** — Korobeiniki (NES, 1989)

All rendered through tube-powered Web Audio API chiptune synthesis.

### 🧱 Tetris
Full tube-powered Tetris clone with:
- All 7 standard tetrominoes
- Next piece preview
- Score tracking
- Keyboard + on-screen tube button controls

### 🚽 Toilet Time
Tube Activity Tracker:
- Precision session timer
- Session history log
- Random productivity tips
- Tube satisfaction status indicator

## Installation

Open `index.html` in any tube-compatible browser.
